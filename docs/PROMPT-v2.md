# Промт итерации 2 — арт-комикс, логотипы компаний, новые портреты, аудит через ECC

Контекст: одностраничный сайт-резюме Дмитрия (React + TypeScript + Vite, Matter.js). Основной промт и правки — в `docs/PROMPT.md`. Эта итерация поверх него.

## Задача
1. Перечитать проект целиком и улучшить там, где это оправдано, не ломая принятые требования (флажок «движение → смена темы», возрастные стили, sticky-полоса возраста, физика шариков).
2. Стиль — **арт-комикс**: тонкие тушевые контуры, чернильные тени, пометки-«реплики», полутоновая точка, графический роман. Самым выразительным остаётся «свободный» стиль (до 30 лет); «сдержанный» и «формальный» сохраняют спокойный вид.
3. Подключить новые логотипы компаний из `comic-logos-6-jpg.zip` (Автоимпорт, SNS, НПП «Александр»; светлая и тёмная версии каждого).
4. Заменить старые портреты новыми: светлая тема — водолазка (новый), тёмная — толстовка, водолазка, пиджак (новые). Остальные светлые портреты (улыбка с бородой, светлый пиджак) сохранены.
5. Активно использовать ECC: аудит агентами `ecc:react-reviewer`, `ecc:a11y-architect`, `ecc:performance-optimizer`, направление дизайна — skill `ecc:frontend-design-direction`.

## Что сделано по аудиту
- Доступность: контраст мелкого текста (токен `--accent-text`, тёмный `--accent-ink`), постоянное имя переключателя темы + `aria-pressed`, `inert` на копиях ленты, отдельная live-область карусели, Esc закрывает подсказку навыка, имя этапа возраста начинается с видимого текста.
- Производительность: preload только портрета текущей темы, `srcset` 480/900, `loading=lazy` для невидимых слоёв, лента не читает layout вне экрана и не крутится при reduced-motion, фиксированный шаг физики, без `window.__skills` в проде, облегчён тёмный фон.
- Логотипы: показываются по теме (CSS по `data-theme`), копии ленты повторяются, пока ширина копии не превысит экран.
- Тёмная тема: акценты холодные синие в тон логотипам, без оранжевого.

## Итерация 5 — клики по карточкам ленты, подпись под персонажем
Промт: найти причину, почему часть карточек в бесконечной ленте не кликается, исправить в корне (по systematic-debugging), убрать подпись под иллюстрациями.
- **Причина:** бесконечная лента состоит из трёх копий списка, и после аудита я пометил копии атрибутом `inert`. Лента почти всё время показывает вторую копию, поэтому видимые карточки были `inert` и не принимали мышь (проверка попадания: 0 из 4). Кликалась только «настоящая» первая копия — отсюда «какие-то да, какие-то нет».
- **Исправление:** `inert` убран. «Настоящая» карточка — `<button>` (клавиатура, скринридер, возврат фокуса), копии — обычные `div` с `aria-hidden`, без фокуса, а клик ловит один обработчик на ленте (`data-co`). Проверка после правки: 4 из 4 открывают именно свою карточку, реальный клик мышью работает, фокусируемых элементов в скрытых копиях 0.
- Подпись под иллюстрацией удалена (компонент и поле `sceneCaption`).
